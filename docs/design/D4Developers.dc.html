Open source. Run the whole thing, read the contract, check every claim yourself.

$ run it

$ git clone https://github.com/abbey188/keyhole && cd keyhole
$ pnpm install
$ ./scripts/verify.sh          # all tests, and the contract has 0 keys
$ ./scripts/testnet-setup.sh   # your own keyless copy on testnet
$ ./scripts/dev-services.sh    # storage, release service and the app
  open http://localhost:5173

$ the contract

Account keyhole-06728d.testnet. No access keys, no upgrade path.

MethodDoes
create_boxMakes a safe, an NFT owned by the caller
create_grantGives access: who, which files, until when
revoke_grantEnds access at once
open_sessionRecords a visit; the key half is released after this is final
close_sessionRecords the end of a visit and extends the log
nft_tokenStandard NFT view (NEP-171)
nft_transferAlways refused: a safe moves only through a hand over
